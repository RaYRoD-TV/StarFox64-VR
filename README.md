# Star Fox 64 VR

Star Fox 64 in VR, built on Starship. Per-eye stereo, motion controllers & a HUD that sits out in the world.

Install it through the [Multiverse VR Hub](https://github.com/RaYRoD-TV/MVRH). It fetches the official Starship release, applies my patch & keeps it updated. Bring your own ROM.

No builds here now.. the hub holds all of it, source included.
